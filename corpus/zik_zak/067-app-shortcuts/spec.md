# Especificación: App Shortcuts

**Template Version**: `zuraffa-1.0`

## Requisitos Funcionales

- **FR-001**: El sistema DEBE guardar el estado de App Shortcuts.
- **FR-002**: El sistema DEBE restaurar la lista de Alerts.

## Escenarios de Aceptación

1. **Given** un usuario conectado **When** abre App Shortcuts **Then** la lista guarda.
   **Type**: acceptance
2. **Given** un dispositivo sin conexión **When** abre App Shortcuts **Then** el marcador se muestra.
   **Type**: widget
