# Especificación: Widget Home

**Template Version**: `zuraffa-1.0`

## Funktionale Anforderungen

- **FR-001**: El sistema DEBE guardar el estado de Widget Home.
- **FR-002**: El sistema DEBE restaurar la lista de Messages.

## Akzeptanzszenarien

1. **Given** un usuario conectado **When** abre Widget Home **Then** la lista guarda.
   **Type**: acceptance
2. **Given** un dispositivo sin conexión **When** abre Widget Home **Then** el marcador se muestra.
   **Type**: widget
