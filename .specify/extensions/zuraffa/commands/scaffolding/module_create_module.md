# Module Create_Module: Generate a ZuraffaPlugin orchestrator for a feature package

## Usage

```bash
zfa module create_module
```

## When to Use

Generate a ZuraffaPlugin orchestrator for a feature package

## Required Parameters

- **name**: Name of the feature

## Flags

| Flag | Type | Required | Default | Description |
|------|------|----------|---------|-------------|
| `--name` | string | Yes | - | Name of the feature |

## Output

Use `--format=json` for machine-readable output. Supports `--dry-run` to preview without writing files.
