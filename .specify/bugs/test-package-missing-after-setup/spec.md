# Bug Spec: test package still missing from dev_dependencies after zfa setup

- **Slug**: test-package-missing-after-setup
- **Issue**: 716 (https://github.com/arrrrny/zuraffa/issues/716)
- **Source**: assessment.md (verdict: likely valid, needs reproduction)
- **Mode**: TDD (bug.fix with `tdd_enabled: true`)

## Problem

`zfa setup` (and `zfa tdd init`) emit tests that import
`package:test/test.dart` (tdd behavior tests written by
`behavior_test_writer.dart`, package scaffold tests in
`package_scaffold.dart`), but the Flutter `dev_dependencies` template
(`PubspecDevDependenciesPatcher.flutterDevDependencies`) omitted the `test`
package. `flutter_test` wraps `test_api`/`matcher` and does NOT provide
`package:test/test.dart`, so generated tests in fresh Flutter projects fail
to compile:

```
Error: Couldn't resolve the package 'test' in 'package:test/test.dart'.
test/tdd/a7_test.dart:16:8: Error: Not found: 'package:test/test.dart'
```

Workaround: `flutter pub add dev:test`.

## Reproduction (from assessment.md)

1. `zfa setup --platforms=ios,android,macos zik_zak_tdd`
2. `cd zik_zak_tdd && zfa tdd init`
3. Copy any spec (e.g. `specs/001-app-bootstrap/spec.md`)
4. `zfa tdd plan 001-app-bootstrap`
5. `zfa tdd gen A7 --feature=001-app-bootstrap`
6. `flutter test test/tdd/a7_test.dart` → compile error

## Acceptance Criteria

- **AC-1**: A fresh project created by `zfa setup` (Flutter mode) has
  `test: ^1.0.0` in `dev_dependencies` in the generated `pubspec.yaml`.
- **AC-2**: A test generated by `zfa tdd gen` that imports
  `package:test/test.dart` compiles and runs under `flutter test` in that
  fresh project (failing, when at all, through an honest-red assertion, not
  a compile/load error).
- **AC-3**: An existing `test:` entry in the generated pubspec is not
  duplicated (patcher stays idempotent).
- **AC-4**: Pure-Dart projects are unaffected: `dartDevDependencies` keeps
  `test: ^1.25.0` and adds no `flutter_test` (bug #688 contract preserved).

## Constraints

- Fix ONLY the pubspec template (`flutterDevDependencies`); do not modify
  test templates.
- One PR for the bug.
