# Bug Fix: `zfa make` crud+vpc+route output compiles — published CachePolicy API, typed path params, gate attribution

- **Slug**: 1675-make-crud-vpc-route-compile
- **Fixed**: 2026-09-18
- **Assessment**: ./assessment.md
- **Status**: applied
- **TDD artifacts**: ./tdd/test-list.md, ./tdd/verification.md (this directory)

## Summary

`zfa make <E> --preset=crud --vpc --route` now emits compiling Dart:
(1) the cache-aware repository delete body calls the `CachePolicy.invalidate`
API the published package actually declares instead of the nonexistent
`markStale`; (2) the route plugin's `zfa make` path forwards the entity's
resolved id field type into the route builder, so path parameters are parsed
per the bound field type (`int.parse(state.pathParameters['id']!)` for
`id:int`) instead of assigning a raw String into the typed view field;
(3) `zfa build`'s analyze gate attributes files `zfa make` just wrote to
generator output instead of labeling them "hand-authored offending (not
generator output)". The full repro compiles through the analyze gate with
zero hand-patching.
