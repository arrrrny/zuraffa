## Body

**Bug**: `zfa di create` generates `*_usecase_di.dart` importing `<entity>_usecase.dart` and referencing `EntityUseCase`, but only `get_<entity>_usecase.dart` + `update_<entity>_usecase.dart` are generated by `zfa usecase create`. Results in ~100 `uri_does_not_exist`, `non_type_as_type_argument`, `undefined_function` errors.

**Reproduction**:
1. `zfa entity create -n MyEntity --field "id:String" --field "name:String"`
2. `zfa usecase create MyEntity` → generates `get_my_entity_usecase.dart`, `update_my_entity_usecase.dart`
3. `zfa di create MyEntity` → generates `my_entity_usecase_di.dart` importing `my_entity_usecase.dart` and using `MyEntityUseCase`
4. `dart analyze` → missing import + undefined type

**Expected**: DI file should reference the actual generated usecase files (`GetMyEntityUseCase`, `UpdateMyEntityUseCase`) or generate a unified `MyEntityUseCase`.

**Files**: `lib/src/plugins/di/builders/di_builder.dart` (or similar DI generation code).
