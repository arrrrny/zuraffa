## Body

Context: Specs 008-012 (auth), 014/084 (Vendure), 042 (Market Fiyati), 017 (Google Shopping), 068 (AdMob), 065 (OtelReporting) depend on live externals. The TDD loop must run them GREEN deterministically without network.

Required (system fix — VISION §9 simulation worlds):
1. `zfa simulate` adapter per service family — a golden contract world (fake API, fake latency, fake failure storms) per VISION §9:
   - FirebaseAuthAdapter: scriptable auth states (signed-in/out, credential errors, deletion flows)
   - VendureAdapter: recorded GraphQL fixtures as golden files, error surfaces
   - RestAdapter (Market Fiyati / Google Shopping / generic): recorded JSON fixtures + latency/fault injection
   - AdMobAdapter: load/show/fail callbacks
   - OtelAdapter: capture-and-assert exporter (spans in-memory)
2. Data sources generated by `zfa make` take the adapter via DI in test bootstrap — the SAME production interface, different certified binding.
3. Fixtures are committed under `specs/<feature>/tdd/fixtures/` and hashed into cycle-log evidence.
4. Network-isolation guard: hosted TDD tests fail if they open a real socket (certify the simulation, prove the isolation).
