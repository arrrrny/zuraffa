// Features

Built to run many browsers, not one.

Everything a human needs to multitask — everything an agent needs to operate.

Isolated Profiles

Run up to 10 independent profiles side by side. Separate cookies, sessions, and storage per profile — zero bleed between your worlds, whether they're yours or your agents'.

Programmatic Tabs

Open, close, group, and address tabs from code. profiles, tabs, groups — a real API surface for scripts and AI agents, not a screen-scraping hack.

Global & Per-Profile Proxy

Route all traffic through one proxy — or give every profile its own exit. Different regions, different identities, running at the same time in the same window.

Tab Pinging

Lightweight keep-alive pings on the tabs that matter. Dashboards, queues, and logged-in sessions stay warm instead of quietly dying in a background tab.

Low Memory

A shared engine and lazy tabs keep the whole farm lean. Run ten profiles where other browsers struggle with three windows — your MacBook fan stays quiet.

At Home on macOS

Keyboard-first, Spaces-friendly, menu-bar aware. It behaves the way a Mac app should — no clunky-afterthought feel.

// For agents

Your agents deserve a real browser.

Screen-scraping a browser that wasn't built for automation is a hack. Zuraffa Browser gives agents first-class, isolated environments — and gives you one window to watch them all work.

  • Spawn a clean identity — an isolated profile with its own cookies and proxy in one call.
  • Drive tabs programmatically — open, group, and address tabs without touching the mouse.
  • Keep watch loops alive — pinging keeps agent dashboards and queues warm for hours.
  • Scale without melting — low-memory design means ten agent profiles is a normal Tuesday.
agent.ts — Zuraffa Browser SDK
import { Browser } from "@zuraffa/browser";

const zb = new Browser();

// isolated identity + its own proxy
const agent = await zb.profiles.create("agent-research", {
  proxy: "socks5://us-east.proxy:1080",
});

// open a tab that never sleeps
await agent.tabs.open("https://status.internal", {
  ping: 15,
});

const tabs = await agent.tabs.list();

// FAQ

Questions, answered.

What exactly is an isolated profile?

A profile is a fully separate browser identity — its own cookies, sessions, storage, and (optionally) its own proxy. You can run up to 10 of them side by side in one window: personal, work, shopping, and a fleet of agent profiles, all without cross-contamination.

How does the trial work?

Download the app and use everything free for 3 days — no feature limits. After the trial, it's a flat $19.99/month to keep going.

Can AI agents control the browser?

Yes — that's a core reason it exists. Profiles and tabs are programmatically manageable: create an isolated profile, attach a proxy, open and group tabs, and keep them alive with pinging, all from code.

How do proxies work?

Set one global proxy for everything, or give each profile its own. Different profiles can appear from different places at the same time — useful for region checks, account separation, and agent fleets.

What does tab pinging actually do?

Background tabs are often frozen or disconnected by browsers to save memory. Tab pinging sends a lightweight keep-alive on a schedule you choose, so logged-in sessions, dashboards, queues, and long-running pages stay live instead of going stale.

Will it eat my RAM like other browsers?

No — a low-memory design (shared engine, lazy tabs) is a first-class goal. Running a whole farm of profiles typically costs a few hundred megabytes, not multiple gigabytes.
