# Contract: SyncMetadataStore

**Feature**: 010-offline-first-sync | **Layer**: Data

## Location

Generated per-entity at: `lib/src/data/datasources/{entity_snake}/sync_metadata_store.dart`

Or shared in Zuraffa core as a generic store if entity-agnostic.

## Purpose

Hive-backed persistence layer that tracks sync status per record WITHOUT polluting the domain entity. Uses a dedicated Hive box per sync-enabled entity.

## Interface

```dart
/// Stores sync metadata in a separate Hive box.
///
/// Keyed by entity identifier (entity.id if present, else entity.hashCode).
/// This keeps the domain entity pure — no sync infrastructure fields.
class SyncMetadataStore {
  SyncMetadataStore(this._box);

  final Box<SyncMetadata> _box;

  /// Get sync metadata for a specific key.
  Future<SyncMetadata?> get(String key);

  /// Store or update sync metadata for a key.
  Future<void> put(String key, SyncMetadata metadata);

  /// Remove sync metadata for a key (after successful remote delete).
  Future<void> remove(String key);

  /// Get all keys with a specific sync status.
  /// Used by the sync strategy to find pending records.
  Future<List<String>> getKeysByStatus(SyncStatus status);

  /// Count records with a specific status.
  Future<int> countByStatus(SyncStatus status);

  /// Clear all sync metadata for this entity.
  Future<void> clear();
}
```

## Hive Configuration

| Property | Value |
|----------|-------|
| Box name | `sync_metadata_<entity_snake>` |
| Key type | `String` |
| Value type | `SyncMetadata` (Hive-adapted) |
| Adapter | Auto-generated by `SyncBuilder` (like cache Hive adapters) |

## SyncMetadata Value Object

```dart
@Zorphy(generateJson: true)
abstract class $SyncMetadata {
  SyncStatus get status;
  int get retryCount;
  DateTime? get lastAttemptAt;
  String? get lastError;
  DateTime? get deletedAt;
  SyncOperation get operation;
}
```

## Key Resolution

| Entity Type | Key Source | Example |
|-------------|-----------|---------|
| Entity with `id` field | `entity.id` | `"prod_123"` |
| Entity without `id` | `entity.hashCode.toString()` | `"8472910"` |

The key resolution is determined at generation time by `EntityAnalyzer` and baked into the generated repository code.
