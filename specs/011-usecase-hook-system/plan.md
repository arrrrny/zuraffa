# Implementation Plan: UseCase Hook System

**Branch**: `011-usecase-hook-system` | **Date**: 2026-06-28 | **Spec**: [specs/011-usecase-hook-system/spec.md](spec.md)

**Input**: Feature specification from `/specs/011-usecase-hook-system/spec.md`

## Summary

Implement a generic hook system that intercepts `UseCase.call()` and `StreamUseCase.call()` at three phases (pre, success, failure). The system follows the existing Zuraffa registry+hook pattern (identical to `FailureReporterRegistry` + `FailureReporter`). Ship a built-in `TelemetryHook` that auto-wraps every UseCase in an OpenTelemetry span, replacing manual `OtelTracer.trace()` calls. Validate the system by implementing ZikZak's `EngagementHook` that replaces 8 manual tracking calls with a single hook registration.

## Technical Context

**Language/Version**: Dart ^3.11.0, Flutter >=3.41.0

**Primary Dependencies**:

- `opentelemetry: ^0.18.11` (existing — used by `TelemetryHook` and `OtelFailureReporter`)
- `logging: ^1.3.0` (existing — used by `HookRegistry` for error logging)
- `meta: ^1.18.0` (existing — `@protected`, `@nonVirtual` annotations)

**Storage**: N/A (framework feature, no persistence)

**Testing**: `flutter_test` with `mocktail` for mocking. Tests in `test/core/` mirroring source structure.

**Target Platform**: All platforms supported by Zuraffa (iOS, Android, macOS, web, Linux, Windows). This is pure Dart framework code — no platform channels.

**Project Type**: Flutter library package (`zuraffa`)

**Performance Goals**: Hook dispatch overhead when no hooks registered: <1 microsecond (single `isEmpty` check). When hooks are registered: fire-and-forget, never blocks the calling UseCase.

**Constraints**: Zero breaking changes to existing `UseCase.call()`, `StreamUseCase.call()`, `FailureReporterRegistry`, or `OtelTracer`. The existing error reporting pipeline remains unchanged.

**Scale/Scope**: 3 new core files (`hook.dart`, `hook_registry.dart`, `telemetry_hook.dart`), 2 modified files (`usecase.dart`, `stream_usecase.dart`), 1 modified facade (`zuraffa.dart`), ~15 unit tests.

## Constitution Check

_GATE: Must pass before Phase 0 research. Re-check after Phase 1 design._

1. **Library-First**: **PASS**. The hook system is a standalone library feature within the Zuraffa package. It is self-contained, independently testable, and has a clear purpose (UseCase interception).
2. **Clean Architecture separation**: **PASS**. Hooks operate at the UseCase layer (domain). They do not touch data sources, repositories, or presentation.
3. **Fail-Fast Contract**: **PASS**. Hooks are fire-and-forget — they never cause the UseCase to fail. The `Result<T, AppFailure>` contract is preserved. Hook errors are caught and logged, not propagated.
