# Implementation Plan: Zuraffa Branding for Generated Apps

**Branch**: `053-zuraffa-branding` | **Date**: 2026-09-01 | **Spec**: [spec.md](./spec.md)

**Input**: Feature specification from `/specs/053-zuraffa-branding/spec.md`

## Summary

Add Zuraffa giraffe branding to all apps generated by `zfa setup` and `zfa make`. This involves modifying `SetupCommand` to copy Zuraffa app icons and brand assets into newly created Flutter/Dart projects, replacing all default Flutter/Dart logos with giraffe imagery, and updating generated READMEs with Zuraffa branding.

## Technical Context

**Language/Version**: Dart 3.11+, Flutter 3.x

**Primary Dependencies**: `package:path`, `dart:io` (existing), Zuraffa brand assets at `assets/zuraffa_app_icons/`

**Storage**: Static asset files (no database)

**Testing**: `dart test` unit tests for the new `BrandingWriter` / branding step class; integration tests that run `zfa setup` in a temp directory and verify brand assets are present

**Target Platform**: Cross-platform CLI (macOS, Linux, Windows)

**Project Type**: CLI tool (Dart package, not a Flutter app)

**Performance Goals**: Branding step adds < 2 seconds to `zfa setup` total time

**Constraints**: Must not break existing `zfa setup` functionality; branding is additive

**Scale/Scope**: Affects 2 commands (`setup` and `make`), 2 app types (Flutter, Dart CLI)

## Feature Implementation Details

### Branding Assets Source

The brand assets are located at `assets/zuraffa_app_icons/` in the zuraffa repository. The directory contains:
- `AppIcon.icon` — Xcode asset catalog source
- `Assets.xcassets/` — iOS AppIcon.appiconset
- `android/` — Android adaptive icon resources (`mipmap-*` directories)
- `appstore.png` — App Store listing image (278KB)
- `playstore.png` — Play Store listing image (113KB)

### BrandingWriter API

```dart
/// Writes Zuraffa brand assets into a generated app project.
class BrandingWriter {
  /// Copies brand assets for a Flutter app:
  /// - app icons to android/app/src/main/res/ and ios/
  /// - store listing images to assets/
  /// - Zuraffa assets to assets/zuraffa_app_icons/
  Future<void> writeFlutterBranding({
    required String projectRoot,
    required bool dryRun,
    required bool verbose,
  });

  /// Copies brand assets for a Dart CLI package:
  /// - Zuraffa logo to assets/
  /// - README header update
  Future<void> writeDartBranding({
    required String projectRoot,
    required bool dryRun,
    required bool verbose,
  });
}
```

### Where to Hook in SetupCommand

`SetupCommand.run()` currently has 8 steps. Add branding as step 5a (between step 5 — deep-link pre-seed — and step 6 — TDD baseline):

```
[5a/8] Applying Zuraffa branding...
  ✓ Copied app icons to android/app/src/main/res/
  ✓ Copied app icons to ios/Runner/Assets.xcassets/
  ✓ Copied store listing images to assets/
```

### Where to Hook in MakeCommand

`MakeCommand` generates entity code. It should also apply branding if not already present — check for existence of `assets/zuraffa_app_icons/` and skip if already branded.

### Icon Configuration Updates

For Flutter apps, after copying icon files, also update platform config files to reference the new icons:

- `ios/Runner/Info.plist` — set `CFBundleIcons` to use Zuraffa app icon
- `android/app/src/main/AndroidManifest.xml` — already handled by ManifestWriter, no change needed for icons
- `pubspec.yaml` — add `assets/zuraffa_app_icons/` to the assets declaration

### README Branding

Append or prepend a Zuraffa banner to the generated README:

```markdown
# {AppName}

![Zuraffa](assets/zuraffa_app_icons/appstore.png)

Powered by [Zuraffa](https://github.com/arrrrny/zuraffa) — Build with confidence.
```

## Risks & Mitigations

| Risk | Mitigation |
|------|------------|
| Brand assets path changes | Use a `BrandAssetConfig` class with a default path; allow override via `.zfa.json` |
| Large asset files slow down setup | Copy only what's needed per platform; store listing images are optional |
| Existing projects re-run branding | BrandingWriter skips if assets already exist (idempotent) |
